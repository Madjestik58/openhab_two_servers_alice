# openhab_two_servers_alice
Задача - на один аккаунт Яндекс Алиса транслировать /управлять данными с двух серверов Openhab 5. Производится автоматическая регистрация созданных на сервере без доступа к Алисе Items с тэгом `Yandex`. И последующая ретрансляция их на сервер с доступом к Алисе.
Работа через Ohcloud.ru и binding https://github.com/Pshatsillo/OpenhabYandexAlice

# Yandex Alice: установка на двух серверах openHAB 5
Один и тот же `org.openhab.io.yandexalice-5.2.3-two-server.jar` установите на оба сервера. На каждом оставьте только одну версию этого дополнения: удалите старый JAR Yandex Alice из `/usr/share/openhab/addons/`, затем положите туда новый. Дождитесь запуска дополнения в openHAB.

## Сервер без Алисы — источник Items

1. Присвойте нужным Items тег `Yandex`.
2. Откройте **Настройки → Дополнения → Yandex Alice**. Поле **«Адрес сервера без Алисы»** оставьте пустым.
3. Ничего другого в настройках дополнения не вводите. Состояние моста должно сообщать, что на этом сервере он выключен.

## Сервер с Алисой — приёмник Items
Наличие binding https://github.com/Pshatsillo/OpenhabYandexAlice и подключенного Ohcloud.ru.
1. Откройте **Настройки → Дополнения → Yandex Alice**.
2. В поле **«Адрес сервера без Алисы»** введите адрес первого сервера, например `http://имя-или-IP:8080`, и сохраните. Адрес должен быть доступен **с сервера с Алисой**. Не добавляйте `/rest` в конце.
3. Подождите несколько секунд и обновите страницу настроек. Проверьте **«Состояние моста Items»** и **«Состояние потока событий»**. При успешной связи появится число зеркальных Items. Если Items не найдены, проверьте тег `Yandex` на первом сервере.
4. Остальные поля для базовой работы оставьте пустыми. Если состояние показывает отказ REST `401` или `403`, введите **API-токен первого сервера** в поле **«API-токен второго сервера»** и снова проверьте состояние.

Тег `Yandex`, префикс зеркальных Items `alice_remote_` и интервал 10 секунд заданы по умолчанию. На новой установке их менять не требуется.

## Нужны ли другие биндинги

Для связи двух серверов **другие биндинги не нужны**. В JAR включены используемые им библиотеки. Биндинги MegaD, MQTT, Modbus и другие устанавливаются только там, где они нужны для ваших реальных устройств.

Для команд Алисы извне должен быть доступен адрес обработчика на **сервере с Алисой**: через openHAB Cloud Connector либо настроенный вами внешний HTTPS-адрес. Cloud Connector нужен только при использовании myopenHAB; на сервере без Алисы он для моста не требуется. Адрес обработчика — `/yandex/v1.0/` на сервере с Алисой.

## Дополнительные функции

- **ID навыка Яндекса и OAuth-токен**: вводите вместе на сервере с Алисой, только если нужны обратные уведомления Яндексу об изменениях состояний. Для голосовых команд они не нужны.
- При замене уже работающей установки сохраните прежний **префикс зеркальных Items**. Его изменение меняет имена Items и идентификаторы устройств Алисы.
