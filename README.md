# openhab_two_servers_alice
Мост openHAB и Алисы
 На сервере с Алисой должны работать Cloud Connector, подключение к ohcloud.ru и привязка нужного аккаунта Яндекс
 На обоих серверах должны быть установлены Remote openHAB Binding  и org.openhab.io.yandexalice-5.1.5-remote-bridge.
Роли (пример)
Сервер без доступа к Алисе — сейчас x.x.x.99. Здесь находятся исходные Items с тегом Yandex.
Сервер с Алисой — сейчас x.x.x.100. Он подключён к ohcloud.ru и аккаунту Яндекса; здесь общий JAR создаёт зеркала и передаёт команды.
IP в поле моста указывается только на сервере с Алисой через ohcloud.ru (x.100): http://x.x.x.99:8080. На сервере без доступа к Алисе (x.x.x.99) это поле пустое.
В настройках JAR версии 5.1.5.202611050007 вместо «второго сервера» используется «сервер без доступа к Алисе». 
Сам openHAB на сервере без Алисы уже предоставляет REST API и поток событий. На 20.99 поле адреса оставлено пустым.

Все новые Items на сервере без Алисы автоматически публикуются на сервер с Алисой - по тэгу "Yandex" в Items
